# AI Rules

This repository uses RojoTemplateV1.

## Source of truth
- The user's local project is canonical.
- When working through GitHub, read the latest `ai-sync` branch, not `main`.
- Read `version.txt`, `default.project.json`, and the relevant files under `src/` before editing.
- `.build/`, `.tools/`, and `_versions/` are generated/runtime data. Do not edit them.

## Versioning
`version.txt` is one line:

`0.0.0_UpdateName`

Rules:
- `V1` is considered immutable once reached.
- `0.X.0` is reserved for a major system or notable milestone.
- `0.0.X` is for normal features, fixes, tuning, hotfixes, and other smaller changes.
- `UpdateName` must be very short.
- EVERY distributed AI update MUST include an updated `version.txt`, even when only one source file changed.

## Update packages
- Include only `version.txt` plus files that changed.
- Preserve exact project-relative paths.
- Do not place update files inside an extra wrapper folder.
- Never include `.build/`, `.tools/`, `_versions/`, or `.git/`.

## Project hash
The launcher computes ONE deterministic SHA-256 project hash from:
- `default.project.json`
- every file under `src/`, including relative paths

There is no file manifest. A changed, added, deleted, renamed, or edited source file changes the single project hash.

`.rojo-template/STATE.json` is generated by the launcher after a successful versioned build. Do not hand-author it.
